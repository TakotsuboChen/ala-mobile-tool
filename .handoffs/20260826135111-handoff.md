## 3. 决策与理由

- **movePoint 相邻约束 + epsilon** [V]——`sortedBy` 在 x 越过相邻点时交换 index，但 `draggingIndex` 不变 → 指向错误点 = 瞬移。约束 x 在 `[leftX+ε, rightX-ε]` 保证排序不变。ε=0.001f（归一化空间约 0.3dp）视觉不可见但严格防止重合。
- **采样列表加入控制点 x** [V]——均匀网格 `i/64` 几乎不包含控制点 x，`lineTo` 在陡峭段偏离实际曲线。加入控制点 x 后曲线在该处有精确顶点。否决方案：`Path.cubicTo`（Hermite 切线转贝塞尔控制点有精度损耗，代码更复杂）。
- **128 步 + 去重** [V]——64→128 步基础密度翻倍；控制点 x 与网格点太近时去重（`x - prevX < 0.0001f`）避免零长度线段。
