## 3. 决策与理由

- **active pointer 跟踪** [V]——`event.rawY`(=`getRawY(0)`) 在多指按下/抬起后 pointer index 重新排列，index 0 可能不是控制踏板的手指。用 `findPointerIndex(activePointerId)` + `getRawY(pointerIndex)` 替代，pointerId 在手指按下期间不变。
- **ACTION_POINTER_DOWN 消费不改变 active pointer** [V]——踏板始终由第一指控制，第二指按下不影响。
- **ACTION_POINTER_UP 检查 active pointer** [V]——主手指抬起重置踏板，非主手指抬起忽略。
- **提取 resetPedalState()** [V]——消除 ACTION_UP/ACTION_CANCEL/ACTION_POINTER_UP 间的重复代码。
