## 3. 决策与理由

- **carController hook（FixedUpdate RVA + 0xA8）** [V]——FixedUpdate 尾跳进 carController（`b 0x1A645CC`），差值恒定。真正生效的是 per-wheel usesABS 写入（RoadForce 门控）。否决方案：只 hook HandleABS——死方法，永不触发。
- **技术解析与工程笔记分离** [V]——用户要求论文体（纯科学结论 LaTeX/Mermaid 化）；模块 hook 机制、可调参数、验证清单外移至 `MODULE_ABS_NOTES.md`。
- **公式用 GitHub 稳定语法而非 $/$$** [V]——GitHub 渲染链是"先 Markdown 后 math"，定界符内不是保护区；math 代码块和反引号定界让公式完全绕过 Markdown 处理器。已固化为持久记忆。
- **篇章编号追加式** [V]——共享方法篇固定 §1，新篇章成篇时取下一个可用编号追加，不预分配规划篇编号（用户明确要求顺序随内容动态联动）。
- **固定偏移 0xA8 计算 carController 地址** [V]——8.0.0 和 8.0.4 中差值一致。后续可正规化为配置传递。
