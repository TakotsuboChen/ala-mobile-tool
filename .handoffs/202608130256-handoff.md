# Ala Mobile 8.0.4 适配研究 — 偏移量变更分析

## 概述

Ala Mobile 8.0.4 (versionCode 200146) 的 libil2cpp.so 相比 8.0.0 (200142) 有系统性偏移。
Instance field 布局完全不变，所有方法 RVA 按类区域有固定 delta。

## 关键发现

### 偏移量变化模式

| 类区域 | 8.0.0 → 8.0.4 Delta | 说明 |
|---|---|---|
| IRDSCarControllInput | +0xDC1C | 游戏逻辑代码一致性偏移 |
| IRDSDrivetrain | +0xDC1C | 同上 |
| IRDSPlayerControls | +0xDC1C | 同上 |
| BillingManager | +0x6340 | 独立偏移区，可能因增加新类 | 
| handleMusicVolume | +0xDDCC | Unity 组件代码偏移 |
| AudioSource.set_volume | -0x1A32384 | **Unity 引擎版本变更** |

### Instance Fields（全部不变，已验证）

- IRDSCarControllInput: 0x16C, 0x170, 0x174, 0x178, 0xD0, 0x108, 0x98, 0xC4, 0xC6
- IRDSDrivetrain: 0xBC, 0xC0, 0xB4, 0xB8
- BillingManager: 0x20, 0x21, 0x22
- IRDSPlayerControls: 0x60

### 重大风险

**AudioSource.set_volume** 的 RVA 从 0x324246C 变为 0x18100E8（-0x1A32384），
暗示 Unity 引擎版本出现了重大变化（可能是 Unity 6 / Ignite 升级）。
如果 Unity 引擎版本升级，IL2CPP 运行时行为可能有细微差异，
需要实机测试验证：ShadowHook 是否仍兼容、类初始化顺序、GC 行为等。

## 已修改文件

1. `app/.../offsets/OffsetTable.kt` — 所有方法 RVA 更新为 8.0.4 值
2. `app/.../util/VersionGate.kt` — 版本号改为 8.0.4 (200146)
3. `native/src/unlock_hook.c` — 三个 fallback 硬编码偏移更新为 8.0.4 值
